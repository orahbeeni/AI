Main view. Sidebar: search, Lists/Board, lists grouped by category, a status pill only when a link needs attention. Hovering a row shows the drag handle and the open-details arrow.

Drag a file from the file manager onto an item: only a link is saved. Dropping between rows makes a new item. Right-click a link: Open, Show in folder (file pre-selected), Copy path; More… holds Re-link and Open with.
